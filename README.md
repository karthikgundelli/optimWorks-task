 E-Commerce Website Simulation
A frontend-only e-commerce application built with React.js featuring authentication, role-based access, and shopping workflows for users and vendors.

✨ Features
User & Vendor authentication

Role-based dashboards

Product management for vendors

Cart, checkout & order history for users

LocalStorage used as mock backend

🛠 Tech Stack
React.js

React Router

Context API

CSS

LocalStorage

▶️ Run Locally
npm install
npm run dev
📌 Roles
User – Browse, add to cart, checkout

Vendor – Add & manage products
